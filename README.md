## 🌟 Overview
First impressions matter! This interactive command-line tool asks you a few simple questions about your skills, bio, and socials, and instantly generates a stunning, badge-rich `PROFILE_README.md` to make your GitHub account stand out.

## ✨ Key Features
- 🪄 **Interactive Prompt**: Easy to use Q&A terminal interface.
- 📛 **Auto Badges**: Automatically generates beautiful tech stack shields.
- 📊 **Stats Integration**: Pre-configured to include GitHub stats cards.

## 🚀 Getting Started

### Prerequisites
Make sure you have `Python` installed on your local machine.

### Installation
```bash
git clone https://github.com/HafezMosleh/github-profile-readme-maker.git
cd github-profile-readme-maker
python3 -m pip install colorama
```

### Usage
```bash
python3 main.py
```
