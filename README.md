# github-profile-readme-maker

CLI tool to generate beautiful, dynamic GitHub profile READMEs.

## Features
- 🚀 Fast and optimized
- 🔒 Secure by default
- 🛠 Easy to configure

## Installation
```bash
git clone https://github.com/HafezMosleh/github-profile-readme-maker.git
cd github-profile-readme-maker
```
